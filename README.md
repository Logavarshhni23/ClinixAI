# ClinixAI — Chronic Disease Detection Using Lifestyle Data & Symptoms

> Multi-disease differential diagnosis platform trained on 4,920 clinical instances across 41 chronic, metabolic, cardiovascular, respiratory, and acute conditions. Powered by ensemble Random Forest classification, clinical symptom severity scoring, and a Next.js 14 clinical UI.

## How the logic works (corrected)

A symptom checker must not turn a few basic symptoms into a disease. The problems found in the earlier version and how each is handled now:

| Problem | Fix |
|---|---|
| The Random Forest *must* pick one of 41 diseases (no "healthy / minor" class), so "fatigue + headache + cough" came out as e.g. *Paralysis* | Every prediction is cross-checked against the disease's own symptom profile built from the dataset. A match is only shown as "likely" when **(1)** the model is at least 50% sure, **(2)** at least 2 of the selected items really occur in that disease, **(3)** at least one is a *distinctive* symptom (occurs in 4 or fewer diseases) and **(4)** at least 60% of the selected items are explained by it. Otherwise the result is **"No clear match"**. Thresholds are in `backend/app/core/config.py`. |
| Generic symptoms (fatigue, vomiting, fever, headache ...) occur in 10-17 diseases each | They can never create a confident disease label on their own (0% pass rate when only generic symptoms are chosen, tested on 3,000 random sets) |
| Dataset columns that are not symptoms were selectable: `prognosis` (a data artefact), `family_history`, `history_of_alcohol_consumption`, `extra_marital_contacts`, blood transfusion / unsterile injections, `obesity`; plus a duplicate `foul_smell_ofurine` | Hidden / merged. History and exposure items are shown in a separate **"Risk factors & history"** group and do **not** count towards the 3-symptom minimum |
| "Severity" was only the sum of symptom weights, so four mild symptoms looked like an emergency while one dangerous symptom could be hidden | Urgency now comes from **red-flag rules** (`knowledge.py`): chest pain with breathlessness/sweating, stroke signs (one-sided weakness, slurred speech, confusion, coma), fever with stiff neck, bleeding, severe dehydration, liver failure. They show an urgent-care warning even when no disease can be matched |
| Disease names had dataset typos ("Peptic ulcer diseae", "Osteoarthristis", "Paroymsal") and every condition looked the same | Clean display names, and each condition is tagged **Chronic / Acute-Infectious / Emergency / Recurrent** |
| Selected symptoms that do not fit the top match were silently ignored | They are listed as "Not typical of X: ..." so the user knows other causes should be considered |
| The project is about *lifestyle data* but no lifestyle input existed | New optional **Lifestyle & Health Profile** and a lifestyle risk screening (below) |
| Symptom selection used keyword filters, so many symptoms were in no category, categories overlapped, and meaningless "w:3" weights were shown | Redesigned selection: search, a common-symptoms list, and browsing by 13 body areas covering **every** symptom, with per-area selection counts |

**Minimum input:** at least 3 real symptoms, **or** a lifestyle profile (age, sex, height, weight). With fewer than 3 symptoms the symptom matching is skipped (the model was never trained on 1-2 symptoms) and only the lifestyle screening is returned.

## Lifestyle Risk Screening

| Condition | Method |
|---|---|
| Type 2 Diabetes | **Indian Diabetes Risk Score (IDRS)**, published screening score for Indian adults (age, waist, physical activity, family history; max 100). 60 or more = high, 30-59 = moderate, under 30 = low |
| Hypertension | Count of 9 established risk factors (age, BMI, salt, inactivity, smoking, alcohol, short sleep, family history, low fruit/veg). 5+ = high, 3-4 = elevated |
| Heart disease | Count of 9 established risk factors (age/sex, smoking, BMI, inactivity, diet, family history, known BP, known sugar, heavy alcohol) |
| Obesity / metabolic | BMI with WHO Asia-Pacific cut-offs (23 overweight, 25 obese) plus South-Asian waist cut-offs (90 cm men / 80 cm women) |

The risk-factor counts are an educational screening aid, **not** probabilities. Personalised advice (activity, salt, sleep, check-ups ...) is generated from the factors that apply.

**Limitations (be honest about these in the report/viva):** the symptom model is trained on a clean synthetic dataset (4,920 rows, only 304 unique symptom patterns, 120 rows per disease), so its 100% accuracy does not show real-world performance, and it treats all 41 diseases as equally common. This tool is an educational estimate, not a medical device.

## 41 Covered Conditions

* **Cardiovascular & Circulatory:** Heart attack, Hypertension, Varicose veins
* **Metabolic & Endocrine:** Diabetes, Hypoglycemia, Hypothyroidism, Hyperthyroidism
* **Respiratory & Pulmonary:** Bronchial Asthma, Pneumonia, Tuberculosis, Common Cold
* **Hepatic & Gastrointestinal:** GERD, Peptic ulcer disease, Gastroenteritis, Chronic cholestasis, Jaundice, Hepatitis A, Hepatitis B, Hepatitis C, Hepatitis D, Hepatitis E, Alcoholic hepatitis
* **Infectious & Viral:** Malaria, Dengue, Typhoid, Chicken pox, AIDS
* **Neurological & Musculoskeletal:** Migraine, Cervical spondylosis, Paralysis (brain hemorrhage), (vertigo) Paroxysmal Positional Vertigo, Arthritis, Osteoarthritis
* **Dermatological & Immune:** Fungal infection, Allergy, Drug Reaction, Acne, Psoriasis, Impetigo, Dimorphic hemorrhoids(piles), Urinary tract infection

## Setup & Running

### 1. Backend — Start the API Server

```powershell
cd backend

# Train model (already trained, run only if you modify dataset)
python train.py

# Run FastAPI server
python -m uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

* **API Docs (Swagger):** http://localhost:8000/docs
* **Health Check:** http://localhost:8000/api/v1/health

### 2. Frontend — Start the Web Application

```powershell
cd frontend

# First time only (node_modules is not included in the zip)
npm install

# Run dev server
npm run dev
```

* **Web Application:** http://localhost:3000

## API Endpoints

### `POST /api/v1/predict`
```json
// Request  (symptoms and lifestyle are both optional, but one of them is needed)
{
  "symptoms": ["polyuria", "increased_appetite", "blurred_and_distorted_vision", "fatigue"],
  "lifestyle": {
    "age": 45, "sex": "male", "height_cm": 170, "weight_kg": 82, "waist_cm": 98,
    "activity": "sedentary", "smoking": "current", "alcohol": "regular", "sleep_hours": 5,
    "eats_fruit_veg_daily": false, "high_salt_diet": true, "sugary_food_daily": true,
    "family_diabetes": "one_parent", "family_hypertension": true,
    "family_heart_disease": false, "known_high_bp": false, "known_high_sugar": false
  }
}

// Response (abridged)
{
  "symptom_analysis_performed": true,
  "predicted_disease": "Diabetes",
  "condition_type": "Chronic",
  "confidence_score": 0.78,
  "is_conclusive": true,
  "status_message": "...",
  "severity_level": "Moderate",
  "red_flags": [],
  "differential_diagnoses": [ { "disease": "Diabetes", "probability": 0.78, "condition_type": "Chronic", "matching_symptoms": ["..."] } ],
  "unexplained_symptoms": [],
  "lifestyle": {
    "bmi": 28.4, "bmi_category": "Obese",
    "conditions": [ { "condition": "Type 2 Diabetes", "risk_level": "High", "score": 60, "max_score": 100, "factors": [ ... ] } ],
    "advice": [ "..." ]
  }
}
```
`422` is returned when there are fewer than 3 real symptoms and no usable lifestyle profile.

### `GET /api/v1/symptoms`
Returns the 131 selectable symptoms with `label`, `weight`, `group` (body area) and `is_symptom` (false for risk factors / history).

### `GET /api/v1/diseases`
Returns all 41 conditions with clean names, descriptions and precautions.

### `GET /api/v1/metrics`
Returns model accuracy, cross-validation metrics, and cohort statistics.
